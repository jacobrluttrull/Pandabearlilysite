# PandaLily Carrd source assets

Downloaded from <https://pandabearlily.carrd.co/> on 2026-09-03.

These are the native image and video files served by the existing Carrd site,
grouped by their source section and retaining Carrd's asset IDs. The YouTube
preview image is stored under `credits/youtube-RkBsFK242Kk.webp` and came from
the video's `i.ytimg.com` thumbnail URL. The looping Starting Screen is stored
under `credits/video03.mp4`.

This directory is outside `static/` intentionally. Treat these as source files:
select, rename, optimize, credit, and copy only the assets actually used by the
site into `static/images/`.
